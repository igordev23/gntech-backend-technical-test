# Segurança

Não abra issues públicas com segredos, credenciais ou dados pessoais.

Para reportar uma vulnerabilidade, use o recurso privado **Security → Report a vulnerability** do GitHub neste repositório. Inclua apenas os passos mínimos de reprodução, sem dados sensíveis.

Este é um repositório de teste técnico. Não há dados reais de usuários nem ambiente de produção.
